🌐 Modern Cars Website

A visually appealing, multi-page static website showcasing modern cars using HTML, CSS, and JavaScript.
The project focuses on clean design, image galleries, card-based layouts, and smooth navigation — perfect for portfolios, demos, or learning web development.

🚗 Overview

The Modern Cars Website is designed as a digital showroom for car enthusiasts.
It includes a home page, card-based model listings, and gallery sections displaying a wide range of modern cars in a clean, stylish layout.
The website is built with a beginner-friendly stack and organized folders for easy maintenance and future expansion.

✨ Features

-   Homepage
-   Car Gallery
-   Card-Based Car Listings
-   Project Cars Section
-   QR Code for sharing

🛠️ Tech Stack

-   HTML5 – Structure
-   CSS3 – Styling, layout, responsiveness
-   JavaScript – Interactivity and UI behaviors

📈 Future Enhancements

-   Search & Filter
-   Responsiveness
-   Lazy Loading
-   More Interactivity
-   JSON Data Integration
